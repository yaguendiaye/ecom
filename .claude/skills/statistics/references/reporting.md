# Reporting results for each audience

## Translating statistical terms

| Technical | For SMEs | For trainers (explain as) |
|---|---|---|
| Mean | Average | Sum ÷ number of values; sensitive to extremes |
| Median | The middle value — half are above, half below | Better for sales, incomes, prices |
| Standard deviation | How much the values usually vary | Typical distance from the average |
| 95% confidence interval | "Most likely between X and Y" | Range that captures the true value in 95 of 100 repeated samples |
| Margin of error ±4 pts | "Give or take 4 points" | Half-width of the CI |
| Statistically significant (p < 0.05) | "The difference is real, not luck" | Unlikely if there were truly no difference; does not mean large or important |
| Not significant | "We can't be sure there is a difference — maybe more data is needed" | Absence of evidence ≠ evidence of absence |
| Correlation | "They tend to move together" | Not proof one causes the other |
| Regression coefficient | "Each extra 1 000 FCFA in advertising goes with about X more sales" | Change in outcome per unit change, others held constant |
| Seasonality | "Your usual busy and quiet months" | Repeating pattern within a year |
| Outlier | "An unusual value to check" | Data error or genuine extreme — investigate before removing |

## Template A — SME owner (one page)

```
WHAT WE LOOKED AT: <question, data, period, n>
WHAT WE FOUND (3 bullets max, with numbers in FCFA / % / customers)
WHAT IT MEANS FOR YOUR BUSINESS
WHAT TO DO NEXT (1–3 concrete actions, with expected impact)
HOW SURE ARE WE: <high / medium / low + one-sentence reason>
```
Short sentences, round numbers, one simple chart, no formulas, no p-values.

## Template B — International / regional organization

```
Title, date, author/affiliation
Abstract / executive summary
1. Background and objectives
2. Data and methodology (sources, design, estimators, software)
3. Results (tables: estimate, SE or 95% CI, CV, n; charts with source notes)
4. Discussion (comparison with literature / other countries)
5. Limitations
6. Recommendations
References; technical annexes
```
Passive or neutral voice acceptable; define every indicator; cite standards.

## Template C — Trainers and consultants

```
Learning objective
Key concept (plain definition + formula)
Worked example (small realistic dataset, step by step)
How to do it in Excel / Python / SPSS / Stata
Common mistakes
Exercise (with answer key)
Slide summary (3–5 bullets)
```
Use local, realistic examples (shop sales in FCFA, cooperative members,
enterprise survey in a Member State).

## Number formatting

- Round to meaningful precision; match decimals within a table.
- Thousands separator appropriate to the reader (1 250 000 FCFA in French-style
  documents; 1,250,000 in English).
- Always units, currency, base year, source, n.
- "+5 percentage points" for change in a rate; "+12%" for relative change.
